# Design Context — Http Formatter

> A dark developer tool (curl / PowerShell / fetch → structured HTTP request viewer).
> Design language: **Resend**. Quiet, monospace-forward, code-as-aesthetic.
> Last updated: 2026-10-07.

---

## 1. Visual Theme & Atmosphere

The entire app is draped in pure black (`#000000`) — the void is the canvas. Content floats on the void the way content floats in a photography gallery: lit with intention, nothing competing for attention. The interface treats HTTP traffic like a luxury product — every request and response gets its own icy-bordered panel.

The type system uses two carefully chosen families that match a developer's mental model: **Geist Sans** carries UI, labels, headings, and prose; **Geist Mono** is the first-class visual element for methods, URLs, headers, status codes, and JSON — code is not hidden away, it performs on the stage. A small dose of pill-shaped controls and frost-blue borders gives the whole tool a precise, premium, quietly confident feel.

**Key characteristics**
- Pure black `#000000` background — the void is non-negotiable
- Two-font hierarchy: Geist Sans (UI / prose) + Geist Mono (code / values / HTTP vocabulary)
- Icy blue-tinted borders: `rgba(214, 235, 253, 0.19)` — every structural line has a cold crystalline shimmer
- Pill-shaped buttons and tags (9999px radius), transparent backgrounds
- Multi-color semantic accents (orange, green, blue, yellow, red) for HTTP methods and status codes
- Geist Mono as a design element, not a status row at the bottom
- Whisper-level ring shadows instead of traditional box-shadows

## 2. Color Palette & Roles

### Primary
- **Void Black** `#000000` — page background, panel background. The defining surface.
- **Near White** `#f0f0f0` — primary text, button text, monospace foreground
- **Pure White** `#ffffff` — maximum emphasis (selected row, primary CTA fill)

### Text scale
- **Silver** `#a1a4a5` — secondary text, descriptions, captions
- **Dark Gray** `#464a4d` — tertiary text, de-emphasized labels
- **Mid Gray** `#5c5c5c` — hover states on subtle elements
- **White 60%** `oklab(0.999994 / 0.577)` — semi-transparent white for chrome
- **White Hover** `rgba(255, 255, 255, 0.28)` — button hover on dark

### HTTP method accents (multi-color scale)
- **Orange 10** `#ff801f` — `POST`, `PUT`, `PATCH` (mutating verbs)
- **Orange 4** `#ff5900` at 22% opacity — orange-tinted backgrounds for chips
- **Blue 10** `#3b9eff` — `GET`, `HEAD`, `OPTIONS` (safe verbs) + interactive info accents
- **Blue 4** `#0075ff` at 34% opacity — blue-tinted backgrounds for chips
- **Green 4** `#11ff99` at 18% opacity — success (2xx) backgrounds; full `#22ff99` text
- **Yellow 9** `#ffc53d` — client errors (4xx), warnings
- **Red 5** `#ff2047` at 34% opacity — server errors (5xx), destructive

### Borders & shadows
- **Frost Border** `rgba(214, 235, 253, 0.19)` — the signature. All structural lines.
- **Frost Border Alt** `rgba(217, 237, 254, 0.145)` — slightly lighter, for list rows
- **Ring Shadow** `rgba(176, 199, 217, 0.145) 0px 0px 0px 1px` — blue-tinted shadow-as-border on cards
- **Focus Ring** `0 0 0 8px rgba(0,0,0,1)` + 1px frost outer — accessibility focus state
- **Subtle Shadow** `rgba(0,0,0,0.1) 0px 1px 3px, rgba(0,0,0,0.1) 0px 1px 2px -1px` — rare, only on floating popovers

### Surface overlay
- **White Hover** `rgba(255,255,255,0.28)` — chip / pill hover
- **Row Selected** `rgba(255,255,255,0.06)` — selected row in lists

## 3. Typography Rules

### Font families
- **Sans (UI / prose / headings)** `Geist`, fallbacks `ui-sans-serif, system-ui`
- **Mono (code / values / HTTP vocabulary)** `Geist Mono`, fallbacks `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas`

Both are self-hosted via `@fontsource/geist` and `@fontsource/geist-mono` (already installed).

### Hierarchy

| Role | Font | Size | Weight | Line height | Notes |
|------|------|------|--------|--------------|-------|
| App wordmark | Geist | 14px | 700 | 1.0 | `tracking-tight` |
| Section heading | Geist | 13px | 700 | 1.0 | uppercase, `tracking-[0.08em]`, silver |
| Nav / button label | Geist | 13px | 700 | 1.0 | default bold per working-memory rule |
| Body / description | Geist | 14px | 400 | 1.5 | near-white |
| Caption / meta | Geist | 12px | 500 | 1.4 | silver or dark gray |
| Method badge | Geist Mono | 11px | 700 | 1.0 | uppercase, `tracking-[0.04em]`, pill |
| URL / endpoint | Geist Mono | 13px | 400 | 1.4 | near-white |
| Status code | Geist Mono | 12px | 700 | 1.0 | semantic accent color |
| Header key | Geist Mono | 12px | 400 | 1.4 | silver |
| Header value | Geist Mono | 12px | 400 | 1.4 | near-white |
| JSON body | Geist Mono | 13px | 400 | 1.55 | near-white with semantic accents |
| Inline code | Geist Mono | 12px | 500 | inherits | frost-bordered pill background |

### Principles
- **Two roles only.** Geist Sans does UI and prose; Geist Mono does HTTP vocabulary (methods, URLs, headers, status, body). They never cross.
- **Bold by default for labels and controls.** Per the working-memory font-weight rule, headings, nav labels, and button text are weight 700 — `font-medium` / `font-semantic` silently override the global rule, so use `font-bold` on new labels.
- **Mono IS the brand.** Mono isn't hidden inside `<code>` tags — it carries methods, status codes, URLs, and response bodies as a first-class design element.
- **Tight tracking on mono, monospace on prose.** Mono already locks tracking; leave it alone. Geist Sans uses `tracking-tight` for headings, default for body.

## 4. Component Stylings

### Method chip
- Background: accent-color at 10% opacity (orange / blue / yellow / red)
- Text: full-saturation accent (`#ff801f`, `#3b9eff`, `#ffc53d`, `#ff2047`)
- Padding: 2px 8px
- Radius: 9999px
- Font: Geist Mono 11px weight 700 uppercase, `tracking-[0.04em]`
- Border: none (the tinted background carries it)

### Status code chip
- Background: status-color at 12–18% opacity
- Text: full-saturation status color
- Padding: 1px 6px
- Radius: 4px
- Font: Geist Mono 12px weight 700

### Pill button (primary)
- Background: transparent
- Text: `#f0f0f0`
- Padding: 5px 12px
- Radius: 9999px
- Border: `1px solid rgba(214, 235, 253, 0.19)` (frost border)
- Hover: background `rgba(255, 255, 255, 0.28)` + 120ms ease-out
- Active: `scale(0.98)`

### Solid pill button (high-emphasis CTA)
- Background: `#ffffff`
- Text: `#000000`
- Padding: 5px 12px
- Radius: 9999px
- Font: 13px weight 700
- Hover: `background: #f0f0f0`

### Ghost button
- Background: transparent
- Text: `#f0f0f0`
- Radius: 4px
- No border
- Hover: `background: rgba(255,255,255,0.06)`

### Panels (Request / Response / Headers / Params)
- Background: transparent
- Border: `1px solid rgba(214, 235, 253, 0.19)`
- Radius: 16px (large panels), 8px (sub-panels)
- Inner padding: 24px (large), 16px (medium), 12px (compact)
- Header row: flex with uppercase section label + actions (Copy, Edit, Send)

### Header key/value rows
- Layout: 2-column grid, 200px key column + 1fr value column
- Key: Geist Mono 12px silver, right-aligned
- Separator: 16px gap
- Value: Geist Mono 12px near-white, copy-on-click with toast
- Row border: `1px solid rgba(217, 237, 254, 0.07)` divider between rows
- Hover row: `background: rgba(255,255,255,0.04)`

### Inputs (URL bar, body editor, search)
- Background: transparent
- Border: `1px solid rgba(214, 235, 253, 0.19)`
- Radius: 8px
- Text: `#f0f0f0` (UI) / Geist Mono for code inputs
- Focus: ring shadow `rgba(176,199,217,0.145) 0px 0px 0px 1px` + 1px frost outer
- Placeholder: `#464a4d` (dark gray)

### Tabs (Params / Headers / Body / Auth)
- Background: transparent
- Item: Geist 13px weight 700
- Radius: 8px
- Active: `background: rgba(255,255,255,0.06)` + frost bottom border `1px solid rgba(214,235,253,0.6)`
- Inactive: silver text

### Toolbar / header bar
- Sticky top bar
- Border bottom: `1px solid rgba(214, 235, 253, 0.19)`
- Background: `#000000`
- Height: 56px
- Logo left, request controls center, actions right

### Toast / notification
- Background: `#0a0a0a`
- Border: `1px solid rgba(214, 235, 253, 0.19)`
- Radius: 12px
- Padding: 12px 16px
- Shadow: `rgba(176,199,217,0.145) 0px 0px 0px 1px` + 24px drop shadow
- Auto-dismiss: 2.5s, ease-out fade

## 5. Layout Principles

### Spacing scale (px)
`1, 2, 4, 5, 6, 7, 8, 10, 12, 16, 20, 24, 30, 32, 40, 48, 64, 80`

### Container
- Centered content, max-width 1200px for desktop
- Side padding: 24px on desktop, 16px on mobile
- Generous vertical rhythm between panels (24–32px gap)

### Whitespace philosophy
- **Cinematic black space**: The void IS the whitespace. Panels don't need backgrounds — frost borders and the surrounding black do all the work.
- **Tight content, vast surrounds**: Headers and key/value rows are compact internally but float in vast black space.
- **Typography-led rhythm**: Geist Mono on URLs and method chips carries its own visual weight; surrounding space adjusts to it.

### Border radius scale
- 4px — small chips, status codes, ghost buttons
- 8px — tabs, sub-panels, inputs
- 12px — toast notifications
- 16px — main panels (Request, Response)
- 24px — large section containers
- 9999px — pill buttons, method badges, tags

### Grid
- Top toolbar: full-width, fixed
- Below toolbar: 2-column on desktop (Request | Response side-by-side), stacked on mobile
- Inside each panel: header row + content area, content area is `divide-y` with frost row borders

## 6. Depth & Elevation

| Level | Treatment | Use |
|-------|-----------|-----|
| Flat | No shadow, transparent background | Default — everything on the void |
| Frost Border | `1px solid rgba(214, 235, 253, 0.19)` | All structural lines: panels, inputs, dividers, tabs |
| Ring | `rgba(176, 199, 217, 0.145) 0px 0px 0px 1px` | Shadow-as-border on hover state |
| Subtle | `rgba(0,0,0,0.1) 0px 1px 3px, …` | Only floating popovers and toasts |
| Focus | `0 0 0 8px rgba(0,0,0,1) + 1px frost outer` | Accessibility focus |

**Shadow philosophy**: On a pure black background, traditional box-shadows are invisible — you can't cast a shadow into the void. Depth comes from frost borders and luminance, never from drop shadows.

## 7. Do's and Don'ts

### Do
- Use pure black `#000000` as the page background — never lighten it
- Apply frost borders `rgba(214, 235, 253, 0.19)` for all structural lines
- Use Geist Sans for UI / prose, Geist Mono for HTTP vocabulary — they don't cross
- Apply pill radius (9999px) to method chips and primary CTAs
- Use the semantic accent scale for HTTP methods (orange=POST family, blue=GET family, yellow=4xx, red=5xx, green=2xx)
- Enable `font-bold` on labels and controls (per working-memory rule) — never `font-medium` / `font-semantic`
- Keep shadows at ring level — no traditional box-shadows on the dark canvas
- Use Geist Mono prominently in panels — methods, URLs, headers, status codes, body all carry the brand
- Use `reicon-react` icons only (per working-memory convention)

### Don'ts
- Don't lighten the background above `#000000`
- Don't use neutral gray borders — all borders must have the frost blue tint
- Don't apply Geist Mono to prose, or Geist Sans to HTTP vocabulary
- Don't use box-shadow for elevation on the dark background — use frost borders
- Don't use `font-medium` / `font-semantic` on labels (silently breaks the global bold rule)
- Don't mix accent colors in the same chip — each method gets one
- Don't reintroduce `lucide-react` (per working-memory rule)
- Don't use placeholder URLs or external image hosts

## 8. Responsive Behavior

### Breakpoints
| Name | Width | Key changes |
|------|-------|-------------|
| Mobile | <640px | Single column, Request / Response stacked, toolbar collapses to icon buttons |
| Tablet | 640–1024px | Single column with wider panels |
| Desktop | >1024px | Two-column Request | Response side-by-side, full toolbar |

### Touch targets
- Method chip: 28px minimum height
- Pill CTAs: 32px minimum height with 16px horizontal padding
- Tabs: 36px minimum height

### Collapsing strategy
- Toolbar: full → icon-only buttons below 640px (Send, Copy, Clear stay visible)
- Panels: side-by-side → stacked at <1024px
- Header rows: collapse padding from 24px → 16px at <640px
- Method chips remain identical at all breakpoints

### Font behavior
- Method chip stays 11px (never shrinks)
- URL stays 13px (wraps if needed)
- Status code stays 12px
- Section labels stay 13px uppercase

## 9. Agent Prompt Guide

### Quick color reference
- Background: Void Black `#000000`
- Primary text: Near White `#f0f0f0`
- Secondary text: Silver `#a1a4a5`
- Border: Frost `rgba(214, 235, 253, 0.19)`
- Method accent (mutating): Orange `#ff801f` at 10% bg / full text
- Method accent (safe): Blue `#3b9eff` at 10% bg / full text
- Success: Green `#11ff99` at 18% bg / full text
- Warning: Yellow `#ffc53d` at 18% bg / full text
- Error: Red `#ff2047` at 34% bg / full text
- Focus: `0 0 0 8px rgba(0,0,0,1)` + 1px frost

### Example prompts
- "Render a Method chip for POST: orange `#ff801f` at 10% background, full-saturation text, Geist Mono 11px weight 700 uppercase, pill radius 9999px, padding 2px 8px."
- "Render a Request panel: transparent background, frost border `1px solid rgba(214,235,253,0.19)`, 16px radius, 24px padding, header row with uppercase silver section label + Send / Copy / Clear pill buttons."
- "Render a Header key/value row: 2-column grid 200px/1fr, Geist Mono 12px, key silver right-aligned, value near-white left-aligned, 16px gap between columns, hover `rgba(255,255,255,0.04)`."
- "Render a Status code chip for 200: green `#11ff99` at 18% background, full text, Geist Mono 12px weight 700, 4px radius, 1px 6px padding."
- "Render a pill CTA: transparent background, frost border, near-white text, Geist 13px weight 700, 9999px radius, 5px 12px padding. Hover: white-glass `rgba(255,255,255,0.28)`. Active: scale 0.98."

### Iteration guide
1. Start with pure black — everything floats on the void
2. Frost borders are the universal structural element — not gray, not neutral
3. Two fonts, two roles: Geist Sans for UI, Geist Mono for HTTP vocabulary — never cross
4. Bold labels and controls by default — never use `font-medium` on a label
5. Semantic accent color picks the meaning: orange=POST family, blue=GET family, green=2xx, yellow=4xx, red=5xx
6. Pill shape for CTAs and method chips, 4–16px radius for containers
7. No drop shadows — frost borders and ring shadows only
